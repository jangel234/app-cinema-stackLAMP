# Plataforma de Taquilla Digital - LAMP + Docker

Este proyecto utiliza Docker para garantizar que todos tengamos el mismo entorno de desarrollo.

## Requisitos
- Docker y Docker Compose instalados.

## Cómo empezar
1. Clona el repositorio.
2. Ejecuta el comando:
   ```bash
   docker-compose up -d

## Cómo usar

### Ruta a pagina

### Ruta a DB
